## Added

- Open interactive HTML artifacts from chats, HTML code blocks and Review → All files, with **Preview**, **Code** and **Refresh** controls.
- Previews load neighboring styles, images, fonts, JavaScript modules, JSON, workers and WebAssembly, plus external libraries through the browser's normal network rules.
- View script errors and failed resource requests in the preview's diagnostics panel.

## Fixed

- HTML links with line numbers open the complete original source at the requested line. Non-ASCII text displays correctly without encoding metadata.
- Active previews remain available while in use. Switching between Preview and Code preserves page state.
- Closing a preview leaves other viewers running. Turning remote access off revokes remote previews while preserving local previews and unrelated Tailscale services.
- Preview cleanup failures no longer prevent the relay from starting; cleanup retries automatically.
