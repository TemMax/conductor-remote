The first release of the Conductor Remote app for the Mac.

## What it does

- Runs the relay from the menu bar.
- Shows the state of the relay, Conductor, Accessibility and the phone link.
- Shows the phone link with a QR code to scan.
- Opens a first-run window for the setup, which also replaces the old background service.
- Starts at login.
- Updates itself, and installs an update only while the relay is idle.

## Requirements

- macOS 14 or later on Apple Silicon.
- Conductor.
- Tailscale, for the phone link.
